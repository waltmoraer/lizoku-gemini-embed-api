# lizoku-gemini-embed-api

Minimal Flask app intended for embedding text (placeholder implementation).

Files
- `app.py` - Flask app entrypoint
- `requirements.txt` - Python dependencies
- `zappa_settings.json` - Example Zappa configuration (generated by `zappa init` normally)
- `.gitignore` - Ignore `venv` and temp files

Quick start (PowerShell)

1. Create and activate a virtualenv:

```powershell
python -m venv venv
venv\Scripts\Activate.ps1
```

2. Install dependencies:

```powershell
pip install -r requirements.txt
```

3. Run locally:

```powershell
python app.py
```

4. Zappa deploy (optional):

```powershell
# Install and configure AWS credentials (AWS CLI)
# Initialize zappa (if you haven't): zappa init
zappa deploy dev
```

Notes
- `zappa_settings.json` contains a placeholder s3 bucket. Replace it with your bucket created for Zappa deployments.
- `app.py` includes a simple `/embed` POST endpoint that returns a deterministic fake embedding for testing.

Zappa and Werkzeug compatibility note
-----------------------------------

Zappa (especially versions around `0.54.0`) pins older versions of `Werkzeug` (<1.0). Flask 2.2+ requires `Werkzeug>=2.2.2`, which creates a dependency conflict if you install Zappa into the same environment used for local development.

Recommended approaches:

- Install Zappa only when you're ready to deploy and do so in a separate environment:

```powershell
# create a separate env for deployment
python -m venv venv-deploy
venv-deploy\Scripts\Activate.ps1
pip install zappa==0.54.0
zappa init
zappa deploy dev
```

- Or, if you must use a single environment, install a Zappa-compatible Werkzeug/Flask combination (downgrading Flask) but be aware this may affect local development.
